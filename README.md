# Affiliate Online Marketplace System

## Project Overview
The Affiliate Online Marketplace System is a web-based platform developed to manage and display affiliate products online. It allows users to browse products by category and brand while enabling administrators to manage products, categories, banners, and brand information through an admin dashboard.

The system provides efficient product organization, search functionality, and email communication features using PHPMailer.

## Features
- Product listing and browsing
- Category and brand management
- Admin dashboard for managing products
- Banner and promotional content management
- Product search functionality
- Email notifications using PHPMailer

## Technologies Used
- PHP
- MySQL
- HTML
- CSS
- PHPMailer
